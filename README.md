# S4 Asincrónica Del as-is al to-be

## Descripción del Proyecto
Rediseño de sistemas de software para el agro enfocado en la transición del proceso actual (as-is) al proceso mejorado con soporte digital (to-be), optimizando el registro de cosecha y la generación de reportes.
